# The Funniest Excuse for Skipping a Meeting

make.fun bounty entry. A single line, 200 characters or fewer, that excuses you from a pointless work meeting.

The entry line:

> I cannot make the standup. I stood up during the last one and nobody noticed for 40 minutes.

`main.ts` (Node 22, stdlib only) validates the line against the gate (1 to 200 characters, one line, not only white space) and writes it to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`.
